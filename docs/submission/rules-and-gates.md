# Rules and acceptance boundaries

**Rechecked September 11, 2026.** Rules can change; inspect the official pages
again before submitting. This file records requirements, not acceptance.

## Event requirements

Submit by **September 13, 12:00 EDT = September 14, 00:00 Asia/Shanghai**. The
plan targets September 13 daytime. Select no more than three partner prizes.
Keep meaningful version history and disclose new/reused work, AI assistance and
all actual spec-driven planning/prompts. Meaningful human contribution cannot be
replaced by AI-generated output. The video must be 2–4 minutes, at least 720p,
with human narration and no speed-up; waiting may be edited out. Finalist
judging is a separate commitment shown in the dashboard.
[Official event rules and submission guide](https://ethglobal.com/events/ethonline2026/info/details).

## Selected partner requirements

- **The Graph — Best AI Tooling or AI Use Case (From Scratch):** use live
  provider data as a core dependency and do meaningful AI work with it; provide
  runnable open source and a demo. A local-only dataset or non-AI fallback is
  insufficient for this positioning.
  [Official Graph prize](https://ethglobal.com/events/ethonline2026/prizes/the-graph).
- **Chainlink — Best Confidential Workflow:** register a confidential handler,
  process meaningful sensitive input and integrate it into the product.
  Successful CRE CLI simulation is an allowed evidence lane; it is not hardware
  attestation.
  [Official Chainlink prize](https://ethglobal.com/events/ethonline2026/prizes/chainlink).
- **Privy — Best B2B financial product:** use a Privy wallet and at least one
  real control in a functional business workflow; supply a working demo and
  source.
  [Official Privy prize](https://ethglobal.com/events/ethonline2026/prizes/privy).

The Chainlink liquidation-protection challenge and Continuity awards are not
part of our chosen scope. Do not enroll in a new challenge merely because it
appears on the same partner page. Partner selection/eligibility remains subject
to the form and judges; this kit does not change the participant's selections.

## Internal gates are deliberately stronger than a file checklist

The [manifest](manifest.json) keeps these pending:

| Gate                  | Required evidence before marking it recorded                                                                                                                 |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Public source         | Actual public commit/revision with current files, license and reproducible history; a local origin URL is not proof of visibility or synchronization         |
| Human contribution    | Participant reviews the product, code/trust boundaries and claims; records their actual contributions, not just authorization to run an agent                |
| Prompt reconciliation | Participant checks available material against all actual tools/sessions used; disclose irretrievable history rather than reconstruct exact quotes            |
| Sepolia execution     | Fresh authorized intent; matching propose/decision/execute receipts, events and same-block final state, with distinct human/Privy roles                      |
| Graph AFTER           | Hosted index's new LT/stateVersion events alter the analysis and match the execution proof                                                                   |
| Runtime AI            | Actual configured model response selects valid evidence IDs; record model/version and source bindings without credentials                                    |
| Three live runs       | Three genuine browser/provider runs on reviewed repeatable baselines; not three local harness runs                                                           |
| Public demo           | Independently opened safe demo URL, with private session, secret and transaction capabilities isolated                                                       |
| Human video           | Uploaded actual recording reviewed for duration, resolution, normal-speed human voice, legibility, truthful chain/provider labels and no leaked private data |

These entries being `recorded` means evidence is listed, not that the offline
checker has authenticated it. Dashboard submission is a final separate action.
